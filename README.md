# 闽港医疗科创协作

撮合医疗技术需求与成果，管理保密尽调、排他权和里程碑资金。

## 领域规则（domain.py）

把需求问题、成果能力、知识产权边界、临床资源、资金条件和地域转化责任拆开管理：

- 保密协议生效前，机构只能看到脱敏摘要；合作解锁（未入选、失败、延期）后回落为摘要。
- 匹配分数仅用于建议接洽，不会自动签约；合作单必须基于推荐显式创建。
- 进入尽调要求保密协议已生效，并锁定材料版本、登记双方利益冲突。
- 排他权由双方有权代表签署，按知识产权边界防止同一成果向多方重复承诺，到期自动失效。
- 履约项目依次经过技术攻关、伦理审查、验证、转化、拨款节点；失败或超过宽限期即按约定解锁权利并计算退款。
- 资金方中途退出时，未拨付部分取消、未确认的已拨付转入待退款，并标记资金缺口。
- 主管人员可调取推荐证据、当前权利占用、跨组织待办和每笔资金对应的已确认成果。

`fixtures/domain.json` 保存领域名词和状态样例，便于接口联调时保持一致语义。运行 `python3 service.py --check` 可检查基础配置；执行 `npm test` 可验证健康入口与领域规则。
