# 闽港医疗科创协作

撮合医疗技术需求与成果，管理保密尽调、排他权和里程碑资金。

## 领域规则（domain.py）

平台把需求问题、成果能力、知识产权边界、临床资源、资金条件和地域转化责任拆开管理，核心约束：

- **脱敏先行**：保密协议（NDA）生效前，机构只能看到需求的脱敏摘要；NDA 须由有权代表（姓名+职务）签署。
- **匹配仅建议**：匹配分数只用于建议接洽顺序，同一需求可同时匹配多个成果，分数不产生任何权利。
- **尽调锁定**：进入尽调必须锁定材料版本号，并登记利益冲突；尽调失败即收回秘密材料访问权。
- **排他受控**：排他期须尽调通过、范围落在知识产权边界内、双方有权代表签署；同一需求同一范围不得重复授予；到期自动失效。
- **节点推进**：项目依次经过 技术攻关 → 伦理审查 → 验证 → 转化 → 拨款；延期按约定解锁权利，失败额外解除排他、解锁需求并触发退款。
- **资金对账**：每笔资金绑定里程碑并标记是否对应已确认成果；资金方可中途退出，退出在主管视图中形成资金缺口待办。
- **未入选隔离**：未入选方（从未签 NDA 或尽调被终止方）在任何阶段都看不到秘密材料。

## 接口

```bash
python3 service.py --port 8000
```

| 路由 | 说明 |
| --- | --- |
| `GET /health` | 健康检查 |
| `GET /api/demands` | 需求列表（脱敏摘要） |
| `GET /api/demands/<id>?org=<org>` | 需求详情，按机构身份决定是否返回秘密材料 |
| `GET /api/brief/<demand_id>` | 主管视图：推荐证据、当前权利占用、跨组织待办、每笔资金对应的已确认成果 |

`seed.py` 预置了演示场景：一个需求同时匹配两个成果，高分团队完成尽调并签约排他，基金 A 承诺后中途退出——可直接查询 `/api/brief/DEM-001` 查看完整说明视图。

## 检查与测试

```bash
python3 service.py --check      # 基础配置检查
npm test                        # 健康入口契约测试
python3 -m unittest test_domain # 领域规则测试
```

`fixtures/domain.json` 保存领域名词和状态样例，便于接口联调时保持一致语义。
